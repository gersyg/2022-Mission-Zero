#  Astro Pi: Mission Zero (2021–2022)

This is the code written by **Haris , Nikos , Nikoletta , and Giorgis (me)** (**Team `Dream Team 2`**) from **2nd Gymnasium Chaidari** for the European Astro Pi Challenge: **Mission Zero (2021–2022)**.

Astro Pi is an educational project run by the **Raspberry Pi Foundation** in collaboration with the **European Space Agency (ESA)**, giving students the opportunity to write Python code that runs on Raspberry Pi computers aboard the International Space Station (ISS).

##  ISS Flight Details

Our program achieved flight status and was executed aboard the International Space Station!

* **Execution Date & Time (UTC):** `2022-06-05` from `10:46:34` to `10:47:34`
* **ISS Coordinates:** `1.696, -19.433` *(Over the Mid-Atlantic Ocean, southwest of West Africa)*

##  What the Code Does

1. **Greeting Message:** Scrolls `"Greetings from the 2nd Gymnasium of Chaidari"` across the Sense HAT 8×8 LED matrix.
2. **Pixel Art Display:** Displays a custom 8×8 pixel landscape featuring a blue sky with clouds, a bright sun in the top-right corner, and green grass/plants below for 3 seconds.
3. **Humidity Measurement:** Reads the ambient relative humidity inside the ISS using the Sense HAT humidity sensor (`sense.get_humidity()`) and scrolls the reading across the display.
