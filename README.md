This is the code me and a classmate wrote in 2022 for the ESA x Raspberry Pi project named Astro Pi: Mission Zero.
The Astro Pi is a device made by Raspberry Pi in collaboration with the European Space Agency and has been tested on the international Space Station for the past few years.
More information can be found under https://astro-pi.org/mission-zero
And you can run the code on https://missions.astro-pi.org/mz/code_submissions/new
